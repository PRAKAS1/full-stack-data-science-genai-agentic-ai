# Full Stack Data Science, GenAI and Agentic AI

This repository contains practical learning material for a full-stack data science and AI journey. The current module introduces core Python data structures through interactive Jupyter notebooks.

## Course Overview

Python is a beginner-friendly language with applications across:

- Data analysis and scientific computing
- Machine learning and artificial intelligence
- Web development and backend services
- Web scraping and automation
- Desktop, game, audio, and video applications
- Testing, DevOps, cloud, and research engineering

The complete course information is available in [info.html](info.html). Open it in a browser for the formatted overview.

## Current Module: Python Fundamentals

The `01-python` directory contains examples for Python's most useful built-in collection types:

| Notebook | Topics |
| --- | --- |
| [list.ipynb](01-python/list.ipynb) | List creation, indexing, mutation, slicing, and common operations |
| [dict.ipynb](01-python/dict.ipynb) | Key-value storage, lookup, updates, and dictionary operations |
| [set.ipynb](01-python/set.ipynb) | Unique values, membership tests, union, intersection, and difference |

These notebooks are a foundation for working with data in pandas, building algorithms, and solving practical programming problems.

## Running the Notebooks

1. Install Python 3.10 or newer.
2. Install Jupyter Notebook or use the Jupyter extension in VS Code.
3. Open the repository in VS Code.
4. Open a notebook from `01-python` and run the cells from top to bottom.

For a command-line setup:

```bash
python -m venv .venv
```

Activate the environment, then install Jupyter as needed:

```bash
python -m pip install notebook
python -m notebook
```

## Suggested Learning Path

1. Learn Python syntax, variables, control flow, functions, and modules.
2. Practice lists, dictionaries, tuples, sets, and strings with the notebooks in `01-python`.
3. Continue with NumPy, pandas, visualization, and exploratory data analysis.
4. Apply the fundamentals to web development, machine learning, automation, and AI projects.
5. Build a portfolio of tested, documented projects.
