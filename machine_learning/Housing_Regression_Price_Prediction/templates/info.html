ABOUT HOMEWISE

A learning project for home estimates.

Explore how property and neighborhood features can be used in a regression model.

THE PROJECT

From property details to a model estimate

Homewise is a machine-learning demonstration. It uses saved regression models trained on the included USA Housing dataset to estimate a price from five numeric inputs.

Try the estimator ↗
INPUT FEATURES

What the estimator uses

  • Average area income
  • Average house age
  • Average number of rooms
  • Average number of bedrooms
  • Area population
MODEL EVALUATION

How performance is compared

Models are evaluated on a held-out test split. MAE and MSE measure prediction error (lower is better); R² summarizes explained variation (higher is better).

IMPORTANT LIMITATIONS

Not a property appraisal

The model uses area-level averages, not a complete individual property profile. Estimates may be inaccurate and should not be used for buying, selling, lending, insurance, or investment decisions. This project does not provide a guaranteed value or prediction range.
